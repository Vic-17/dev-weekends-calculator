# Tip Calculator & Bill Splitter

A clean, responsive single-page web application that calculates tips and splits bills in real-time with inline validation. Built using native web fundamentals for the Dev Weekends Fellowship 2026 assessment.

### Live Deployed URL
(https://vic-17.github.io/dev-weekends-calculator/)

### How to Run Locally
1. Clone this repository to your machine.
2. Open the `index.html` file directly in any modern web browser. No installations, compilers, or local servers required.

### Project Features
* Live, button-free calculation as you type.
* Graceful inline error validation (no alerts or native tooltips).
* Accessible color contrast and mobile-responsive layout blocks.
